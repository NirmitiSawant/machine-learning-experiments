## 🚀 Getting Started

### Prerequisites

Install Python and Jupyter Notebook. You can also use Google Colab to run the notebooks online.

### Installation

Install the required libraries using pip:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

### Run the Notebooks

1. Clone this repository:

   ```bash
   git clone https://github.com/NirmitiSawant/machine-learning-experiments.git
   ```

2. Navigate to the project folder:

   ```bash
   cd machine-learning-experiments
   ```

3. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

4. Open any `.ipynb` file and run the cells.
